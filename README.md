# Quiz-Application
A simple and beginner-friendly Python Quiz Application that displays multiple-choice questions from a JSON file, takes user input, checks answers, and shows the final score. Easy to run, easy to customize, and perfect for learning basic Python concepts.

A simple and beginner-friendly **Quiz Application** written in Python.  
This project uses a JSON file to store questions and displays MCQs in the terminal.

## 📌 Features
- Multiple-choice questions  
- Score calculation  
- Loads questions from a JSON file  
- Input validation  
- Beginner-friendly and easy to understand
